# 04-数据库

测试数据构造与结果校验的落脚点。测开对数据库的要求是「能查、能造、能看懂慢在哪」，不是 DBA 级调优。

## 学习目标

- 熟练写多表关联与聚合查询，能独立完成数据库层的结果校验
- 看得懂 `EXPLAIN`，能判断一条 SQL 有没有走索引
- 能安全地在测试环境造数据、清数据，不污染他人环境
- 理解事务与隔离级别，能设计并发场景的测试用例

## 计划覆盖的知识点

- SQL 基础：`SELECT` / `WHERE` / `ORDER BY` / `LIMIT`、`GROUP BY` 与聚合函数、`HAVING`
- 多表：`INNER` / `LEFT` / `RIGHT JOIN`、子查询、`UNION`
- DML 与 DDL：`INSERT` / `UPDATE` / `DELETE`、建表与字段类型选择
- 索引：B+ 树、聚簇与非聚簇索引、联合索引最左前缀、索引失效的常见场景
- 执行计划：`EXPLAIN` 各列含义、`type` 与 `key` 怎么看、慢查询日志
- 事务：ACID、四种隔离级别与对应的脏读 / 不可重复读 / 幻读、MVCC、锁与死锁
- 测试相关：测试数据构造脚本、数据清理与回滚策略、`pymysql` / SQLAlchemy 在框架中的封装
- Redis：常用数据结构、缓存穿透 / 击穿 / 雪崩、缓存与数据库一致性带来的测试点

## 常考点

- 找出成绩第二高的记录、每组取 Top N，这类 SQL 现场手写
- 联合索引 `(a, b, c)`，哪些查询能用上索引，哪些用不上
- 四种隔离级别分别解决什么问题，MySQL 默认哪一种
- 什么情况下索引会失效（函数运算、隐式类型转换、`LIKE` 前置通配、`OR` 混用等）
- `DELETE` / `TRUNCATE` / `DROP` 的区别
