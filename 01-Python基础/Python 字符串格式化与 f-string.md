# Python 字符串格式化与 f-string

> 拼日志、拼请求、拼断言信息天天用。三种格式化方式不是“新旧替代”这么简单——理解 f-string 在编译期怎么被处理，才明白它为什么既快又有局限，以及为什么日志不该用 f-string 预拼接。

## 概念

### 1. 三种方式的历史

1. **`%` 格式化**（老式）：`"name=%s" % name`，类似 C 的 printf。逐步被取代。
2. **`str.format()`**（2.6+）：`"{} {}".format(a, b)`，支持位置/关键字/索引，灵活但略冗长。
3. **f-string**（3.6+）：`f"{name}"`，把表达式直接嵌进字符串字面量，可读性最好、性能也好。

### 2. f-string 的底层：编译期处理

f-string 不是运行时“扫描字符串找 `{}`”，而是在**编译阶段**就被转换成了普通的表达式调用。例如 `f"{x}"` 大致等价于 `format(x, "")`，`f"{x:.2f}"` 等价于 `format(x, ".2f")`。因为表达式在编译期就已确定、运行时只是求值并格式化，所以 f-string 通常比 `%`/`format` 更快或持平，且能内联任意表达式。

### 3. 格式化迷你语言（format spec）

`f"{value:[[fill]align][sign][#][0][width][,][.precision][type]}"`：

- 对齐 `<` `>` `^`，填充符放前面：`f"{name:>10}"` 右对齐宽 10
- 千分位 `,`：`f"{1000000:,}"` → `1,000,000`
- 精度 `.2f`：浮点保留 2 位；`.3}` 对字符串截前 3 个字符
- 类型 `d`/`f`/`e`/`%`/`b`/`x`/`o`：`f"{0.9123:.2%}"` → `91.23%`

### 4. 自调试 `=`(3.8+) 与多行(3.12+)

`f"{x=}"` 同时输出表达式文本和值（`x=42`），调试利器。3.12 起 f-string 支持多行、复用引号、内嵌注释，写复杂表达式更自由。

### 5. 为什么日志**不要**用 f-string 预拼接

`log.info(f"user={u}")` 在日志级别不够（如 WARNING 但当前 INFO 关掉）时，**仍会先拼接字符串再被丢弃**，浪费 CPU，且拼接过程若抛异常（如 `u` 不可格式化）会掩盖真正的日志。正确：`log.info("user=%s", u)`——日志框架只在级别满足时才格式化（惰性）。

## 用法

```python
name, score = "alice", 0.9123
print(f"{name} 得分 {score:.2%}")        # alice 得分 91.23%
print(f"{name:>10}")                      # 右对齐宽 10
print(f"{x=}")                            # x=42（3.8+）

# 嵌套表达式
print(f"{user['name']} 登录")
print(f"{'ID':=<8}")                      # 左对齐补 =

# 日志用 % 占位，惰性格式化
import logging
logging.info("user=%s", user)             # 级别不够不格式化
```

## 踩坑

- **f-string 里大段复杂逻辑降可读性**：逻辑重的先算好变量再拼。
- **引号嵌套**：f-string 用双引号时，内部表达式里的字符串要用单引号，否则冲突（3.12+ 才宽松）。
- **`%` 与 `format` 混用易错**：新代码统一 f-string；遗留 `%(name)s` 字典式格式化别和 f-string 搞混。
- **日志用 f-string 预拼接**：级别不够仍会拼接+可能报错，掩盖日志；用 `%s` 占位。
- **`.precision` 对字符串是截断不是四舍五入**：`f"{'abcdef':.3}"` → `abc`，和控制浮点精度是两回事。
- **`{` `}` 要转义**：字面大括号写 `{{` `}}`。

## 面试怎么答

三种格式化：`%` 老式、`str.format` 灵活、`f-string`（3.6+）最推荐。f-string 在编译期转成 `format()` 调用，所以快且能内联表达式；`=` 自调试、`>.2%` 等迷你语言很实用。

关键坑：① f-string 里复杂逻辑降可读性；② 引号嵌套注意；③ **日志不要用 f-string 预拼接**——级别不够仍会拼接甚至报错，用 `log.info("x=%s", x)` 惰性格式化。④ `{` `}` 用 `{{` `}}` 转义。
