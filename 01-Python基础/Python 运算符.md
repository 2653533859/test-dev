# Python 运算符

> 运算符背后是“对象协议”和“求值规则”。`is` 为什么不等于 `==`、`and/or` 返回的是什么、`//` 为什么向下取整——这些不是语法糖，而是 Python 对象模型与数值模型的直接体现。

## 概念

### 1. 运算符本质是“特殊方法调用”

Python 里 `a + b` 等价于 `a.__add__(b)`（若失败再试 `b.__radd__(a)`）；`a == b` 是 `a.__eq__(b)`；`a < b` 是 `a.__lt__(b)`。`and/or/not` 是特例，它们是**控制流**而非方法调用。

### 2. 身份运算符 `is` / `is not`：比的是 `id`

`is` 判断两个名字是否指向**同一个对象**（即 `id(a) == id(b)`），与值无关。这引出两个容易翻车的实现细节：

- **小整数池（integer cache）**：CPython 启动时会预创建 `-5 ~ 256` 的整数对象并复用，所以 `a = 256; b = 256; a is b` 为 `True`；但 `257` 每次都是新对象，`a is b` 为 `False`。
- **字符串驻留（intern）**：短字符串、纯字母数字下划线组成的字符串，解释器会 intern（复用同一份），所以 `a = "abc"; b = "abc"; a is b` 常为 `True`；含空格或动态拼接的通常不复用。

结论：**永远用 `==` 比较值，用 `is` 只比较单例身份（`None`/`True`/`False`）**。

### 3. 逻辑运算符 `and` / `or`：短路 + 返回操作数

`and` / `or` 是**短路求值**，并且**返回的是最后一个被求值的操作数**，而不是强制的 `True/False`：

- `x and y`：若 `x` 为假，直接返回 `x`（不求值 `y`）；否则返回 `y`
- `x or y`：若 `x` 为真，直接返回 `x`；否则返回 `y`

```python
print(0 or "default")        # "default"
print(1 and 2)               # 2
print([] and "x")            # []   （假值被原样返回）
```

### 4. 除法与取模的整数模型

- `/` 永远返回 `float`（`3 / 2 == 1.5`）
- `//` 是**向下取整（floor）**：结果向负无穷取整。`7 // 2 == 3`，但 `-7 // 2 == -4`（不是 -3）
- `%` 取模满足 `a == (a // b) * b + (a % b)`，所以符号**随除数**：`-7 % 3 == 2`（不是 -1）

这套规则保证 `a % b` 的结果符号与 `b` 一致，和 C/Java（`-7 % 3 == -1`）不同，处理负数下标/循环时要小心。

### 5. 比较链与运算符优先级

`a < x < b` 等价于 `a < x and x < b`，但 `x` 只求值一次（避免属性访问/函数调用的副作用）。优先级（高→低）：算术 > 比较(`<`,`==`) > 成员/身份(`in`,`is`) > 逻辑(`not` > `and` > `or`)。括号 `()` 永远最高。

### 6. 海象运算符 `:=`（3.8+）

在表达式内完成赋值并返回值，避免重复计算：

```python
if (n := len(data)) > 10:
    print(f"太多：{n}")
```

## 用法

```python
# is 只比身份
a = [1]; b = [1]
print(a == b, a is b)        # True False

# and/or 返回操作数
name = user_name or "anonymous"
port = config.get("port") or 8080

# 向下取整与取模
print(-7 // 2, -7 % 3)       # -4 2

# 比较链
x = 5
print(0 < x < 10)            # True，等价于 0 < x and x < 10

# 海象避免重复正则匹配
import re
if (m := re.search(r"\d+", text)):
    print(m.group())
```

## 踩坑

- **用 `is` 比值**：`if x is 256` 对小整数“碰巧”成立、对大整数失败，最隐蔽的 bug 之一；值比较一律 `==`，身份比较只用于 `None`/`True`/`False`。
- **`and`/`or` 不是布尔**：`flag = a or b` 拿到的是对象不是 `True`/`False`；要布尔结果用 `bool(a or b)` 或显式 `flag = True if (a or b) else False`。
- **`//` 负数方向**：分页/分组 `start = (page-1)//size` 遇负数易错；需要“向零取整”用 `int(a/b)`。
- **`%` 对负除数**：结果符号随除数，和 C 系语言不一致，做索引回绕要验证。
- **`==` 可被重载且可能抛异常**：自定义类重写了 `__eq__`，`==` 不一定返回 bool（虽然约定应返回 bool），比较未知对象时别假定一定安全。
- **链式比较里的函数只调一次**：`0 < f() < 10` 中 `f()` 只调用一次，别误以为会调两次。

## 面试怎么答

核心考 `==` vs `is`：`==` 比的是值（走 `__eq__`），`is` 比的是对象身份 `id`。`is` 在 `-5~256` 小整数和短字符串驻留下会出现“反直觉为 True”的情况，所以值比较用 `==`，`is` 只用于 `None`/`True`/`False` 这类单例。

`and`/`or` 是短路且**返回最后求值操作数**（不是 bool）；`//` 向下取整（负数向负无穷）、`%` 符号随除数，和 C 不同。比较链 `a < x < b` 等价于 `a<x and x<b` 但 `x` 只求一次。优先级：算术 > 比较 > 成员/身份 > 逻辑，括号最高。
