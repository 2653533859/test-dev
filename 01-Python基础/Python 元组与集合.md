# Python 元组与集合

> 元组做“不可变记录/多返回值/可哈希键”，集合做“去重/集合运算”。理解元组为什么不可变、集合为什么无序且元素必须可哈希，才能用对场景。

## 概念

### 1. 元组：不可变的序列

`tuple` 是**不可变序列**，底层类似“定长指针数组”，创建后不能增删元素、不能重赋值 `t[0]`。它没有 `append`/`pop` 等方法。

**为什么不可变是特性而非限制：**
- **可哈希**：不可变 → 哈希稳定 → 能作 dict 键、`set` 元素（`(1,2)` 可以，`[1,2]` 不行）
- **线程安全**：多线程共享只读数据无需加锁
- **性能**：定长结构，创建/访问略快于 list
- **语义清晰**：表示“固定结构的记录”（如坐标、多返回值）

**单元素陷阱**：`(1)` 是 `int`，`(1,)` 才是元组——逗号决定元祖身份，不是括号。

**解包**：`a, b = (1, 2)`、`a, *rest = (1,2,3)`，解包常用于函数多返回值。

**元组里的可变元素**：`t = ([1], 2)`，`t[0].append(3)` 合法（元组没变，它引用的 list 变了），所以“不可变”指元组结构，不保证内容。

### 2. 集合：哈希集

`set` 是无序、不重复、元素必须可哈希 的容器，底层是哈希表（和 dict 类似，只存键不存值）。

- **去重**：插入重复元素被忽略
- **集合运算**：`&` 交 `|` 并 `-` 差 `^` 对称差
- **成员判断 O(1)**：比 list 的 `in` O(n) 快
- **无序**：没有索引、不能切片、不保证遍历顺序（CPython 3.7+ 有某种顺序但**不应依赖**，因为依赖哈希随机化）

**空集**：`set()` 不是 `{}`（`{}` 是空 dict）。

**`frozenset`**：不可变集合，可哈希，能作 dict 键 / set 元素。

## 用法

```python
point = (10, 20)
x, y = point                 # 解包
single = (1,)                # 单元素元组，注意逗号

a = {1, 2, 3}
b = {3, 4, 5}
print(a & b, a | b, a - b, a ^ b)   # {3} {1,2,3,4,5} {1,2} {1,2,4,5}

# 保序去重（set 不保序）
seen = list(dict.fromkeys([1, 2, 2, 3]))   # [1, 2, 3]

# 权限子集判断
required = {"read", "write"}
print(required <= {"read", "write", "admin"})   # True
```

## 踩坑

- **单元素元组漏逗号**：`(1)` 是 int；函数返回单值元组务必 `(x,)`。
- **空集合是 `set()`**：`{}` 是空 dict。
- **集合无序**：`s[0]` 报错、不能切片；需要顺序用 list 或 `dict.fromkeys`。
- **集合元素必须可哈希**：放 list/dict 会 `TypeError`；要存复合元素用 `tuple` 或 `frozenset`。
- **去重丢失重复与顺序**：只想要“出现次数”用 `collections.Counter`。
- **`pop` 对 set 随机删**：无序，别假设删哪个。
- **哈希随机化**：Python 对 str/bytes 的哈希加了随机盐（防止哈希碰撞 DoS），同一进程内顺序稳定，跨进程不保证——别依赖 set 遍历顺序。

## 面试怎么答

元组是不可变序列，可哈希、线程安全、略快，常做多返回值和固定记录；单元素要 `(1,)` 逗号，解包 `a,b = t`；元组结构不可变但内部可变元素仍可改。

集合是无序、去重、元素可哈希的哈希集，成员判断 O(1)；交并差用 `&|^-`；空集用 `set()`；需要可哈希集合用 `frozenset`。去重丢失顺序和计数，保序去重用 `dict.fromkeys`，计数用 `Counter`。
