# 10-安全测试

面向功能测试同学的安全能力：能在日常测试中主动发现常见漏洞，而不是等安全团队兜底。

**范围约束**：本模块笔记只覆盖在自己有权限的测试环境、靶场（DVWA、Juice Shop、pikachu）和 CTF 环境中的验证方法。不记录针对无授权目标的攻击手法。

## 学习目标

- 熟悉 OWASP Top 10，看到一个功能能说出它可能有哪些安全风险
- 能用抓包改包的方式验证越权、参数篡改、重放这类逻辑漏洞
- 会用扫描工具做基础检测，并能人工确认结果不是误报
- 输出可复现的漏洞报告：影响、复现步骤、修复建议

## 计划覆盖的知识点

- 基础概念：漏洞 / 威胁 / 风险、黑白灰盒、渗透测试流程、常见安全术语
- OWASP Top 10 逐项：失效的访问控制、加密失败、注入、不安全设计、安全配置错误、脆弱组件、身份认证失败、软件与数据完整性、日志监控不足、SSRF
- 注入类：SQL 注入原理与验证、参数化查询为什么能防、命令注入、XSS（存储型 / 反射型 / DOM 型）与转义、CSRF 与 Token 防护
- 逻辑漏洞（测开最容易发现的一类）：水平与垂直越权、支付金额篡改、验证码绕过、短信轰炸、并发导致的重复提交与超卖、任意用户密码重置
- 认证与会话：弱口令、Token 未失效、会话固定、JWT 常见问题
- 传输与配置：HTTPS 配置、敏感信息泄露（接口返回多余字段、日志打印明文、源码与备份文件暴露）、目录遍历、文件上传绕过
- 工具：Burp Suite（Proxy / Repeater / Intruder）、sqlmap、OWASP ZAP、Nmap、依赖漏洞扫描（`pip-audit`、Trivy、Dependency-Check）
- 靶场实践：DVWA、Juice Shop、pikachu
- 安全接入研发流程：SAST / DAST / SCA 在 CI 里的位置

## 常考点

- 讲一下 SQL 注入的原理和防御方案（为什么参数化查询有效，转义为什么不够）
- XSS 三种类型的区别，防御要做在输入还是输出
- CSRF 与 XSS 的区别，Token 防 CSRF 的原理
- 水平越权和垂直越权怎么测，测试用例怎么设计
- 一个下单接口，你会从哪些角度找安全问题
- 越权和逻辑漏洞为什么扫描器扫不出来
